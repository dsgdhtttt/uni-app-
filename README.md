# uni-app开发仓库管理小程序

源码地址：ym7k.com/17777/

传统中小仓库、门店库房、商贸企业很多还依靠纸质台账或者表格记录库存，出入库登记慢、盘点耗时长、库存数据不同步，经常出现错发、漏发、账实不符等问题。基于 uni-app 开发的仓库管理小程序，一套代码可适配微信小程序、APP 等多端使用，聚焦库存流转、单据管理、盘点核对、权限分配等核心业务，不用采购昂贵的大型仓储系统，适合小微企业、门店库房、小型加工厂落地轻量化仓储管理。

小程序前端面向仓管人员使用，操作简洁，适配手机随时作业。入库管理是基础模块，支持新增入库单，选择供应商、货品分类，录入货品名称、规格、批次、数量、存放库位，支持扫码录入，扫描货品条码快速带出货品信息，减少手动输入错误。入库单据提交之后自动保存记录，同步更新库存数量，单据可随时查看与检索。出库流程和入库对应，领料单、销售出库单统一管理，选择货品、填写出库数量、领用人员，出库完成后库存自动扣减，每一笔出库都留下完整记录，方便后续追溯。

库存查询与库位管理方便仓管实时掌握货品状态。工作人员可以按货品名称、分类、库位、批次条件组合查询库存，快速查看当前可用数量、预警库存。系统支持设置库存上下限，当货品数量低于最低库存时自动预警提醒，及时发起采购，避免缺货停工；库存过高也会提示，帮助管理者控制积压。库位标签化管理，可以划分不同库区、货架位置，货品绑定对应库位，找货、理货效率明显提升。

盘点功能是这套系统的重点，告别纸质盘点表。支持创建盘点任务，选定盘点范围，仓管拿着手机现场扫码核对实物数量，录入实盘数量，系统自动对比账面库存，生成盘盈盘亏清单。盘点完成后可一键确认调整库存，生成盘点记录存档，每一次盘点的时间、操作人员、差异明细都可追溯，解决定期盘点工作量大、容易出错的痛点。

单据和台账模块汇聚全部业务流水。所有入库单、出库单、调拨单、盘点单独立归档，支持按时间、单据类型检索查看，单据详情清晰展示货品明细、操作人、操作时间。支持货品调拨，处理不同库位之间货品转移，调拨完成双向同步库存数据。各类库存台账、出入库流水支持导出，方便财务对账、汇总统计。

后台负责基础数据维护与权限管控。管理员可以维护货品档案、分类信息、供应商信息、库区库位信息，统一维护基础资料。权限分级机制适配团队协作，不同账号分配不同权限，普通仓管只允许出入库、盘点操作，无法修改基础配置；管理人员可以查看全部报表、导出数据；可单独设置只读账号，只用于查询库存。后台数据看板直观展示出入库趋势、库存总量、预警货品清单、单据数量，直观反映仓库运转情况。

依托 uni-app 跨端特性，项目一次开发，多端同步上线，仓管人员用小程序就能作业，不需要专门采购手持终端设备，降低硬件投入。系统拓展性良好，后续可按需增加采购申请、客户管理、简单对账模块。这套小程序把扫码出入库、库存预警、盘点对账、单据追溯整合在一起，用低成本的数字化方式替代手工台账，帮助中小型仓库规范货品流转流程，减少库存差错，提升仓储管理效率。
